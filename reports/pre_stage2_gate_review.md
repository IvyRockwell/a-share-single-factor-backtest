# 阶段 2 前置问题核实报告

审计日期：2026-09-15。此报告只核实后续研究的数据边界；没有清洗数据、建立股票池、计算因子或启动阶段 2。

## 已固定的研究范围和口径

- 正式研究期：2014-09-12 至 2025-12-31；2026 年交易、PE 和基准记录不进入正式研究样本。
- 候选市场：`Markettype` 为 1、4、16、32，即沪深 A 股、创业板和科创板。
- 基准：`H00300`；日收益使用 `Idxtrd08 / 100`，指数收盘值使用 `Idxtrd05`。已核对该收益与相邻收盘指数变化一致，最大舍入差为 0.0001 个百分点。
- ROE 候选输入：年度 `Typrep=A` 的净利润、年末所有者权益和有效 `Actudt`。
- PE：`PE1TTM` 暂按 `TradingDate` 视为可用日。这是研究假设，不是当前文件能够证明的事实；正式结果均保留了前视风险说明。

## 新增文件与覆盖情况

| 文件 | 字段 | 覆盖 | 用途 |
| --- | --- | --- | --- |
| `STK_LISTEDCOINFOANL.csv` | `Symbol`, `EndDate`, `LISTINGDATE` | 年度快照 2013-12-31 至 2025-12-31 | 验证首次上市日早于研究日。 |
| `STK_ITEMCHANGE.csv` | `Symbol`, `DeclareDate`, `ChangeDate`, `ChangedItem`, `ValueBefore`, `ValueAfter` | 变更实施日 2013-12-31 至 2025-12-31 | 识别暂停上市、退市整理期、终止上市等状态变更。 |

上市日期文件有 53,417 条记录、5,764 个代码，`Symbol + EndDate` 无重复，且同一代码没有相互冲突的首次上市日期。状态变更文件有 2,343 条记录；其中 461 条为“上市状态”变更，覆盖 275 个代码。状态变更以 `ChangeDate` 为实际生效日；`DeclareDate` 仅保留为公告信息，不用于替代实施日期。

## 研究期交叉核实结果

在当前主表中，候选市场共有 5,557 个代码，其中 120 个未出现在新增上市日期文件中；它们均没有研究期日交易记录，因此不构成研究期实际交易候选。研究期内实际有日交易记录的股票为 5,418 个、共 10,669,834 条日交易记录，全部具有首次上市日期。

| 检查 | 结果 |
| --- | ---: |
| 研究期实际交易代码 | 5,418 |
| 实际交易代码缺少首次上市日期 | 0 |
| 上市日前交易记录 | 0 |
| 终止上市实施日之后仍有交易记录 | 0 |
| 候选市场代码发生上市状态变更 | 251 |
| 候选市场代码没有上市状态变更记录 | 5,306 |

“没有上市状态变更记录”不被解释为“历史上始终正常上市”。阶段 3 按调仓日建立股票池时，仅将同时满足以下条件的记录作为可判断候选：有日交易记录、交易日不早于 `LISTINGDATE`、未落入终止上市后或下述状态不确定区间；`Trdsta` 继续保留，用于记录该日的交易状态。当前主表的最终状态不可反向用于判断早期日期。

## 状态变更冲突与处理规则

461 条状态变更中发现 4 个相邻事件的“前一条变更后状态”和“下一条变更前状态”不连续。不能忽略这些源数据冲突，因此定义为状态不确定区间：

| 代码 | 不确定区间内交易 | 处理 |
| --- | ---: | --- |
| `600200` | 2025-12-10 至 2025-12-29，共 14 条，`Trdsta=1` | 该区间内的调仓日必须排除。 |
| `600701` | 2021-03-15 至 2021-04-26，共 30 条，`Trdsta=1` | 该区间内的调仓日必须排除。 |
| `600432` | 2017-05-27 至 2018-05-29，无交易记录 | 无实际调仓候选，不额外处理。 |
| `600806` | 2017-05-24 至 2018-05-29，无交易记录 | 无实际调仓候选，不额外处理。 |

其他状态变更按 `ValueAfter` 从 `ChangeDate` 起生效：出现“终止上市”后，股票不再作为候选；“暂停上市”和“退市整理期”被保留为状态标记，具体是否排除由阶段 3 的股票池规则确定。

## ROE、PE 与基准的前置结论

- 年度合并利润与年末合并权益可连接 62,508 条；其中 59,595 条有有效 `Actudt`。这些披露日均晚于报告期末，滞后 8 至 274 天，因此阶段 4 按披露日控制了可用时间。
- `PE1TTM` 仍缺少与其 TTM 分母对应的公告日期、报告版本和可用日期证据。按 `TradingDate` 使用是本研究的暂定规则，而非消除前视偏差的证明。
- `H00300` 的 `Idxtrd08` 是百分数日收益；阶段 2 已统一转换为小数，避免与 `Dretwd` 的小数收益混用。

## 前置核实结论

研究期可固定为 2014-09-12 至 2025-12-31。新增上市与状态文件足以为研究期实际交易股票提供上市日期和状态事件证据；4 个状态冲突已被明确定位，含交易记录的 44 个不确定日由阶段 3 的股票池规则排除。2026 数据明确不进入正式研究样本。

本报告不解除 PE 的前视风险：后续所有使用 `PE1TTM` 的结论均已注明“按交易日可用”的暂定假设。
